# 🐾 Mochi Tamagotchi

**Mochi** — Telegram-тамагочи, о котором можно заботиться одному или вместе с другим человеком.

Корми, играй, обустраивай комнату, собирай редкие предметы, выполняй задания и наблюдай, как у вашего Mochi появляется своя маленькая история. 💛

## ✨ Что умеет

- 🍓 **Уход за Mochi:** кормление, игры, ласка, сон и разные варианты действий.
- 🤝 **Совместная игра:** два хозяина могут заботиться об одном питомце и поддерживать общий streak.
- 🎮 **Мини-игры:** небольшие игры с наградами, XP и монетами.
- 📅 **Ежедневные задания:** новые цели каждый день и бонус за полное выполнение.
- 🎲 **Случайные события:** Mochi может сам найти монеты, предметы или попасть в небольшое приключение.
- 🛍 **Магазин и коллекция:** ежедневная ротация товаров и предметы разных редкостей.
- 🎁 **Редкие дропы:** некоторые вещи нельзя купить — только найти.
- 🏆 **Достижения:** награды за прогресс, коллекцию, streak и другие активности.
- 📜 **История Mochi:** важные моменты жизни питомца сохраняются в отдельном журнале.
- 💭 **Состояния и реакции:** Mochi реагирует на уход и меняет настроение в зависимости от своих показателей.

## 🎮 Основные команды

| Команда | Что делает |
| --- | --- |
| `/start` | Начать игру |
| `/screen` | Открыть главный экран Mochi |
| `/profile` | Профиль и статистика питомца |
| `/history` | История важных событий |
| `/promo КОД` | Активировать промокод |
| `/cancel` | Отменить текущее действие |

## 🚀 Запуск

Нужен **Python 3.11+** и токен Telegram-бота.

1. Установи зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Создай `.env`. Если в проекте есть шаблон, скопируй его:

   ```bash
   cp .env.example .env
   ```

   Или создай файл вручную. Минимальная конфигурация:

   ```env
   BOT_TOKEN=токен_бота
   ADMIN_IDS=123456789
   ```

   Для нескольких администраторов:

   ```env
   ADMIN_IDS=123456789,987654321
   ```

3. Запусти бота:

   ```bash
   python bot.py
   ```

## 🔒 Безопасность

Никогда не загружай в публичный репозиторий:

```text
.env
mochi.db
mochi.db-wal
mochi.db-shm
__pycache__/
```

В `.env` находится токен Telegram-бота, а в `mochi.db` — данные и прогресс игроков.
