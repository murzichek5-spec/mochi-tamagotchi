# Mochi 🐱💞

**Mochi** — Telegram-тамагочи для пар и друзей. Два человека могут заботиться об одном питомце, развивать его, выполнять совместные действия, собирать предметы, обустраивать комнату и поддерживать общий streak.

## 🚀 Обновление за месяц

За последний цикл обновлений Mochi заметно вырос из простого тамагочи в полноценную небольшую игру.

### 📅 Ежедневные задания

- Каждый день генерируется **4 новых задания** для конкретного Mochi.
- Квесты дают 🪙 монеты и XP.
- За выполнение всех 4 заданий выдаётся дополнительный бонус.
- Прогресс общий для двух хозяев одного питомца.

### 🎲 Случайные события

- Mochi периодически переживает самостоятельные события между заходами игроков.
- События могут менять сытость, настроение, энергию, любовь или давать монеты.
- Добавлены редкие события с предметными дропами.
- Расписание хранится в SQLite, поэтому после перезапуска событие не выдаётся повторно.

### 🎮 Мини-игры

Добавлены три мини-игры:

- 📦 **Три коробки**
- ✊ **Камень · бумага · ножницы**
- 🔢 **Больше или меньше**

Мини-игры дают монеты, XP и настроение. Для наград действует общий cooldown, а повторные/одновременные callback-запросы защищены от двойной выдачи.

### 🤝 Совместный streak

- Streak подтверждается **только успешным совместным действием двух хозяев**.
- Обычные кормление, игра, ласка, `/profile`, `/screen` и обновление экрана серию не увеличивают.
- За один календарный день можно получить только +1 к streak.
- Хранятся текущая серия и личный рекорд Mochi.

Добавлены достижения за серии:

- 3 дня
- 7 дней
- 14 дней
- 30 дней
- 60 дней
- 100 дней

### 👤 Профиль Mochi

Команда `/profile` показывает:

- возраст и стадию питомца;
- уровень и XP;
- текущие статы;
- совместный streak и рекорд;
- количество кормлений, игр, ласки, сна и совместных действий;
- статистику мини-игр и случайных событий;
- прогресс ежедневок;
- коллекцию предметов по редкости;
- достижения.

### 🎒 Редкость предметов

Все 55 предметов получили редкость:

- ⚪ Обычный
- 🟢 Необычный
- 🔵 Редкий
- 🟣 Эпический
- 🟡 Легендарный

Редкость отображается в магазине, коллекции и сообщениях о покупках/дропах.

### 🛍 Ежедневная ротация магазина

Магазин больше не показывает весь каталог сразу.

Каждый день для конкретного Mochi формируется новый ассортимент:

- 8 обычных предметов;
- 4 необычных;
- 3 редких;
- шанс появления эпического;
- небольшой шанс появления легендарного.

Оба хозяина видят одну и ту же ротацию. Сервер дополнительно проверяет ассортимент при покупке, поэтому старый callback нельзя использовать для покупки уже недоступного предмета.

### 🎁 Event-only предметы и редкие дропы

Часть предметов нельзя купить за монеты — их можно получить только через редкие случайные события.

Сейчас к таким предметам относятся:

- ⭐ Звёздный ковёр
- 🎣 Удочка-дразнилка
- 🌸 Цветущий горшок
- ⏰ Часы-котик
- 🌃 Окно: ночной город

Дубликаты event-only предметов не выпадают. После полного сбора эксклюзивной коллекции редкий дроп заменяется компенсацией монетами.

### 📜 История Mochi

Добавлена команда `/history` и переход из профиля.

В историю записываются важные моменты:

- рождение;
- взросление;
- новые достижения;
- полное выполнение ежедневок;
- покупки новых предметов;
- редкие дропы;
- переименование.

История разбита на страницы, поэтому журнал не превращается в одно огромное сообщение.

### 🍓 Вариативное кормление

После нажатия «Покормить» можно выбрать один из вариантов:

- 🥣 Обычный корм — бесплатно, +3 сытости;
- 🍗 Премиальный корм — 10 🪙, +6 сытости;
- 🍱 Сытный рацион — 22 🪙, +11 сытости;
- 🍣 Деликатес — 40 🪙, +18 сытости.

Платные действия списывают монеты атомарно вместе с изменением статов.

### 🧶 Вариативная игра

Доступны четыре варианта:

- 🧶 Клубок — бесплатно;
- 🔴 Лазер;
- 🪶 Дразнилка с перьями;
- 🏰 Полоса препятствий.

Разные игры по-разному влияют на настроение, любовь, энергию и сытость.

### ❤️ Вариативная ласка

Три бесплатных варианта с одинаковым эффектом:

- 🤲 Почухать животик;
- 👂 Почухать за ушком;
- 🐾 Почухать попу.

### 💭 Состояния Mochi

На главном экране и в профиле теперь отображается вычисляемое состояние питомца. Оно зависит от текущих статов и автоматически меняется после действий и фоновой деградации.

Примеры состояний:

- 🤒 Плохо себя чувствует
- 🍽 Очень голодный
- 😴 Измотан
- 🌧 Грустит
- 🤪 Перевозбуждён
- 🥰 Счастливый
- 😼 Капризничает
- 💕 Хочет ласки
- ✨ Спокоен

### 💬 Случайные реакции

Кормление, игра, ласка и сон больше не отвечают одной и той же фразой. Добавлены десятки случайных реакций и дополнительные реплики, зависящие от текущего состояния Mochi.

Реакции не меняют скрытно баланс — они влияют только на текст и ощущение живого питомца.

### 📊 Обновлённый интерфейс

Главный экран, профиль и магазин приведены к единому стилю.

Статы теперь отображаются progress-барами:

```text
🍓 Сытость   🟢 ███████░░░ 72%
✨ Настроение 🟡 ██████░░░░ 63%
⚡ Энергия   🟠 ███░░░░░░░ 34%
❤️ Любовь    🟢 ████████░░ 84%
```

Индикаторы:

- 🟢 75–100
- 🟡 50–74
- 🟠 25–49
- 🔴 0–24

XP использует такой же визуальный прогресс. Магазин показывает предметы в одном формате и сортирует их по редкости.

### ⏳ Новая деградация статов

За каждый полный час:

- 🍓 сытость: **−4**;
- ✨ настроение: **−2**;
- ⚡ энергия: **−1**;
- ❤️ любовь автоматически не уменьшается.

Фоновый цикл применяет decay автоматически, а кнопка `🔄 Обновить` использует ту же логику.

## Запуск

Требуется **Python 3.11+**.

Установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте `.env` на основе `.env.example`:

```env
BOT_TOKEN=your_bot_token
BOT_USERNAME=your_bot_username
ADMIN_IDS=123456789
```

Запуск:

```bash
python bot.py
```

## Обновление существующего сервера

Перед обновлением сохраните:

```text
.env
mochi.db
```

Код и ассеты лучше устанавливать в чистую папку, после чего вернуть существующие `.env` и `mochi.db`. При запуске `init_db()` автоматически добавит недостающие таблицы и поля.

Не заменяйте живую базу файлом из релизного архива.

## Безопасность

В репозиторий не должны попадать:

```text
.env
mochi.db
mochi.db-wal
mochi.db-shm
__pycache__/
cache/
```

`BOT_TOKEN` хранится только в серверном `.env`.
